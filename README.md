## Overview

This project implements a **Continuous Attractor Network (CAN)** model of grid cells, following Burak & Fiete (2009). Grid cells in the medial entorhinal cortex (MEC) fire in a hexagonal pattern and are thought to support **path integration** — the ability to update a position estimate from velocity inputs, even in the absence of sensory cues.

We build the model incrementally:
- **Exercise 0:** 1D ring attractor with Mexican-hat connectivity → stable activity bump
- **Exercise 1:** Velocity integration in 1D using two asymmetrically shifted sub-populations
- **Exercise 2:** Extension to 2D → spontaneous hexagonal grid + 2D path integration
- **Exercise 3:** Aperiodic boundary conditions and two correction strategies

## Model summary

All neurons follow a rate model:

$$\tau \frac{ds(x,t)}{dt} = -s(x,t) + I^{rec}(x,t) + B(x,t), \quad r(x,t) = \max(0, s(x,t))$$

Recurrent input is computed by convolution with a **Mexican-hat kernel**:

$$W(x) = A_{exc}\,e^{-x^2/\sigma_{exc}^2} - A_{inh}\,e^{-x^2/\sigma_{inh}^2}$$

In 2D, four directional populations (N, S, E, W) use shifted kernels. Velocity $\mathbf{v}(t)$ asymmetrically modulates their feedforward drives $B_p$, forcing the hexagonal lattice to translate rigidly and encode the integrated position.

## Key parameters

| Parameter | 1D | 2D | Description |
|---|---|---|---|
| $\tau$ | 10 ms | 10 ms | Neural time constant |
| $\Delta t$ | 1 ms | 1 ms | Integration step (Forward Euler) |
| $M$ | 100 | 40 / 50 | Network size per dimension |
| $A_{exc}$ | 0.3 | 1.0 | Excitatory kernel amplitude |
| $\sigma_{exc}$ | 5.0 | 4.8 | Excitatory kernel width |
| $A_{inh}$ | 0.2 | 1.0 | Inhibitory kernel amplitude |
| $\sigma_{inh}$ | 10.0 | 5.0 | Inhibitory kernel width |
| $l$ | 1.0 | 1.0 | Kernel shift (velocity coupling) |
| $\alpha$ | 0.5 | 0.1 | Velocity modulation gain |
| $B_0$ | 1.5 | 1.0 | Baseline feedforward drive |

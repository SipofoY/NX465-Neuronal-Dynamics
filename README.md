## Scientific Background

Grid cells, first discovered in the medial entorhinal cortex (MEC) of rodents by Hafting et al. (2005), exhibit striking hexagonally periodic firing fields as an animal navigates through space. Crucially, this activity persists in complete darkness, demonstrating that grid cells do not merely respond to external sensory input but actively maintain an internal spatial representation via **path integration** — the continuous integration of self-motion (velocity) cues to update a position estimate.

This project implements and analyses a **Continuous Attractor Network (CAN)** model of grid cells, following the theoretical framework of Burak & Fiete (2009). The central hypothesis is that the hallmark hexagonal firing pattern of grid cells emerges spontaneously as a stable attractor state of a recurrently connected neural sheet governed by a **Mexican-hat (difference-of-Gaussians) connectivity kernel** — short-range excitation balanced by long-range lateral inhibition. Velocity-driven path integration is then achieved by breaking the translational symmetry of this attractor through asymmetric feedforward modulation of directional sub-populations.

## Implementation

### Neural dynamics

All neurons follow a first-order rate model governed by:

$$\tau \frac{ds(x,t)}{dt} = -s(x,t) + I^{rec}(x,t) + B(x,t), \qquad r(x,t) = \max(0,\, s(x,t))$$

with time constant $\tau = 10\,\text{ms}$, integrated via **Forward Euler** at $\Delta t = 1\,\text{ms}$.

### Connectivity kernel (Mexican-hat)

$$W(x) = A_{exc}\,e^{-x^2/\sigma_{exc}^2} - A_{inh}\,e^{-x^2/\sigma_{inh}^2}$$

Recurrent inputs are computed as spatial convolutions using `scipy.ndimage.convolve1d` (1D) and `scipy.ndimage.convolve` (2D), with `mode='wrap'` for periodic (torus) and `mode='constant'` for aperiodic boundary conditions.

### Velocity integration

Four directional populations (N, S, E, W) use anatomically shifted kernels $W_p(\mathbf{x}) = W(\mathbf{x} - l\,\hat{e}_p)$ and receive asymmetric feedforward drives modulated by the velocity vector $\mathbf{v}(t) = (v_x, v_y)$:

$$B_N = B_0(1 + \alpha v_y), \quad B_S = B_0(1 - \alpha v_y), \quad B_E = B_0(1 + \alpha v_x), \quad B_W = B_0(1 - \alpha v_x)$$

### Aperiodic boundary correction

A radial masking envelope $e(\mathbf{x}) = \exp\!\left(-\gamma^2\,\max(0,\,\|\mathbf{x}\| - R_{fade})^2\right)$ is applied either to the **outgoing weights** (weight attenuation, Ex. 3.3) or to the **feedforward drive** (input attenuation, Ex. 3.4) to suppress boundary artefacts. As demonstrated by Burak & Fiete (2009), input attenuation better preserves the translation invariance required for accurate dynamic path integration.

## Key Parameters

| Symbol | Value | Description |
|---|---|---|
| $\tau$ | 10 ms | Neural time constant |
| $\Delta t$ | 1 ms | Integration time step |
| $M$ | 100 (1D), 40/50 (2D) | Network size per dimension |
| $A_{exc}$ | 0.3 (1D), 1.0 (2D) | Excitatory kernel amplitude |
| $\sigma_{exc}$ | 5.0 (1D), 4.8 (2D) | Excitatory kernel width |
| $A_{inh}$ | 0.2 (1D), 1.0 (2D) | Inhibitory kernel amplitude |
| $\sigma_{inh}$ | 10.0 (1D), 5.0 (2D) | Inhibitory kernel width |
| $l$ | 1.0 | Kernel shift (velocity coupling) |
| $\alpha$ | 0.5 (1D), 0.1 (2D) | Velocity modulation gain |
| $B_0$ | 1.5 (1D), 1.0 (2D) | Baseline feedforward drive |
| $\gamma$ | 0.08 | Envelope decay rate (aperiodic BC) |

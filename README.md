## Project — Spatial Navigation using Grid Cells

Path integration in Continuous Attractor Networks (CAN) modelling grid cells in the medial entorhinal cortex.

- **Notebook:** `NX_465_Miniproject_2_2026_Solution.ipynb`
- **Report (LaTeX):** `main_mp2.tex` + `images2/`
- **Topics:** 1D/2D ring attractors, Mexican-hat connectivity, velocity integration, grid cells, aperiodic boundaries
